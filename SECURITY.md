# Security Policy

## Supported Versions

| Branch | Supported |
| --- | --- |
| `master` | :white_check_mark: |
| `oss/universal` | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Dwell, please do not disclose it publicly in open issues.

Instead, please report the vulnerability privately by:
1. Opening a **GitHub Private Vulnerability Report** via the **Security** tab of the repository.
2. Or contacting the project maintainer via [GitHub profile](https://github.com/str-VaibhavThakkar).

Please include:
- A description of the issue and potential impact
- Affected component or API endpoint
- Step-by-step reproduction instructions or proof of concept

We will acknowledge receipt of your report within 48 hours and work with you to address and resolve the vulnerability.
